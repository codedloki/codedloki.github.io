Interfaces are ports to connect network devices like switches ,end hosts and routers . Each device has its own interfaces


These interfaces are all RJ45 ports (RJ= Registered Jack)


## RJ45

The RJ45 connectors are used on end of copper ethernet cables . All ethernet cables are not copper cables

## ETHERNET

Ethernet is collection of network protocols and standards

###  Why do we neeed Network Protocols

 Network Protocols are set of instruction to carry out communication between networks 

Think of like two people  cant communicate with each other language not known to the other person  so we find common laguage known to both to communicate.

## Bits and Bytes


Connection and communication in a network occur at set speed .This speed are measured in bits an bytes

* bits are values : 0,1
* bytes values are :Series of 8 bits


** Speed is measured in bits per second **
** Data on Hard Drive measured in bytes per second **


## Measurements

1 Kilobit = 1000 bits
1 Megabit = 10000000 bits
1 Gigabit = 1,000,000,000 bits
1 Terabit = 1,000,000,000,000 bits
